4. المرحلة 1 — الموقع الرئيسي (ابدأ الآن)

الهدف: موقع شركة جديد مثل Brew 92 مع روابط للمتجر والحجز والكيترنق.

الخطوات:

  1. إنشاء مجلد: las-main
  2. فتح المجلد في Cursor — محادثة جديدة
  3. دراسة Brew 92: التخطيط، القائمة، الصفحة الرئيسية، الفروع
  4. خريطة الموقع: الرئيسية، من نحن، الفروع، 3 صناديق روابط
  5. البناء بـ Next.js + ألوان LAS (#003b49, #c68e65)
  6. النشر على lascafe.sa

المخرج: موقع رئيسي حي مع 3 نقاط دخول واضحة.

5. المرحلة 2 — متجر لاس

الهدف: متجر إنتاج متوافق مع الموقع الرئيسي — الطلب والدفع عبر الموقع، واتساب للمتابعة فقط.

الخطوات:

  1. إعادة تصميم lass ليطابق الموقع الرئيسي
  2. ربط بوابة الدفع (Moyasar / Tap)
  3. حفظ الطلبات (Supabase)
  4. النشر على store.lascafe.sa

6. المرحلة 3 — حجز الطاولات

الهدف: تطوير نظام حجز خاص (بديل Bookatables).

  1. تحديد المتطلبات: الفروع، عدد الأشخاص، التاريخ، التأكيد
  2. إنشاء las-booking
  3. البناء والنشر وربطه بالموقع الرئيسي

7. المرحلة 4 — الكيترنق والمناسبات

الهدف: موقع للمناسبات والكيترنق — قائمة، نموذج طلب، متابعة.

  1. تحديد النطاق مع LAS
  2. إنشاء las-catering
  3. البناء والنشر وربطه بالموقع الرئيسي
